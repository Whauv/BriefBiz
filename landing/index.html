ENTRY PAGE FOR BRIEFBIZ

Track the business stories that matter without reading the whole internet.

BriefBiz turns startup, venture, and business coverage into a fast, high-signal experience. Users can explore market-moving news, inspect company narratives, and follow a founder-first view of what changed, who is involved, and why it matters.

PIPELINE
INSTALLATION

Get BriefBiz running locally

1

Clone the repository and create backend/.env from the provided template.

2

Run docker compose up --build to start Postgres, Redis, Elasticsearch, the API, workers, and frontend.

3

Open the app, configure API keys if you want AI summaries or email digests, and launch the product from the live BriefBiz app.

Quick start
git clone https://github.com/Whauv/BriefBiz
cd BriefBiz
docker compose up --build
